# Бот рейтингу шкільного бюджету

Кожні 15 хвилин GitHub Actions парсить 64 проєкти з
[smartregion.pl.ua/sb](https://smartregion.pl.ua/sb) і публікує в Telegram пости
з офіційним рейтингом категорії проєкту №53 (від 1 місця до №53), оцінкою межі фінансування
і тим, скільки голосів бракує до сусідів:

- **раз на годину** — плановий пост без звуку;
- **одразу, зі звуком** — коли №53 когось обганяє або його обганяють.

Старі пости не редагуються, тож у чаті зберігається вся історія.

## Як рахується рейтинг

За [Положенням](https://smartregion.pl.ua/documents/sb) переможців визначають не за сирими голосами:

- **Три окремі рейтинги** — проєкти міських, селищних і сільських громад (п. 7.6).
  №53 (Зіньківська міська рада) змагається лише з міськими.
- **Остаточний бал = голоси × √ВК**, де ВК = населення області / населення громади
  (додаток 3). Чим менша громада, тим «важчий» голос.
- **Переможці** — з верху рейтингу категорії, доки вистачає коштів (п. 7.7);
  за однакового балу вище той, хто просить менше (п. 7.8).

Категорію, коефіцієнт і суму кожного проєкту бот бере з [`contest.json`](contest.json) —
їх перенесено з офіційних рейтингів на сторінці «Документи». Логіка — у [`ranking.py`](ranking.py).

**Межа фінансування — оцінка.** На ШГБ 2026 обласна програма передбачає 6 млн грн. Як їх ділять
між категоріями, у Положенні не прописано; у 2025 році — пропорційно кількості проєктів, а наступний
проєкт отримував залишок. Бот рахує так само (`TOTAL_BUDGET` у `ranking.py`).

Сервер не потрібен, усе безкоштовно.

## Налаштування (≈10 хвилин)

### 1. Створіть бота
1. У Telegram відкрийте [@BotFather](https://t.me/BotFather), надішліть `/newbot`, вигадайте назву.
2. Скопіюйте **токен** (вигляду `123456789:AAH...`). Нікому його не показуйте.
3. Відкрийте свого бота і натисніть **Start**: без цього бот не зможе вам писати.

### 2. Дізнайтеся свій chat_id
```bash
./venv/bin/python bot.py --chat-id
```
Вставте токен (його не видно під час введення). Скрипт виведе число: це ваш `chat_id`.

### 3. Завантажте код на GitHub
1. На [github.com/new](https://github.com/new) створіть **Public** репозиторій
   (наприклад, `smart-region-bot`) без README.
2. У цій папці виконайте (замініть `<логін>`):
```bash
git init && git add . && git commit -m "Telegram-бот рейтингу" && git branch -M main
```
```bash
git remote add origin https://github.com/<логін>/smart-region-bot.git && git push -u origin main
```

### 4. Додайте секрети
У репозиторії: **Settings → Secrets and variables → Actions → New repository secret**:

| Name | Значення |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен з кроку 1 |
| `TELEGRAM_CHAT_ID` | число з кроку 2 |

### 5. Запустіть
**Actions → Telegram bot → Run workflow**. За хвилину в чаті з'явиться перший пост.
Далі бот сам перевіряє рейтинг кожні 15 хвилин.

## Корисне

- **Приватний репозиторій.** У `.github/workflows/bot.yml` замініть `*/15` на `*/30`,
  інакше не вистачить безкоштовних 2000 хвилин на місяць.
- **Затримки.** GitHub іноді запускає задачі за розкладом на 5–20 хв пізніше.
  Час кожного поста видно внизу повідомлення.
- **Частота планових постів** — `POST_EVERY` на початку `bot.py`.
- **Інший проєкт чи конкурс.** Змініть `SECTION`, `CONTEST_ID`, `END_ID`, `TARGET_ID` на початку `parser.py`.
  Для іншого конкурсу також оновіть `contest.json` даними з його офіційних рейтингів.
- **Канал або група замість особистого чату.** Додайте бота адміністратором з правом публікувати
  повідомлення. Для публічного каналу в `TELEGRAM_CHAT_ID` можна вказати `@юзернейм_каналу`,
  для приватного каналу чи групи напишіть там будь-що і повторіть крок 2 (id від'ємний).
- **Зупинити бота.** Actions → Telegram bot → `···` → **Disable workflow**.
- **Стан між запусками** зберігається в `state.json`: бот сам комітить його після кожного поста.
- **Перевірити локально без Telegram:** `./venv/bin/python bot.py` надрукує повідомлення в консоль.
